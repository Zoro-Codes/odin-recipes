# odin-recipes

This project is part of The Odin Project Foundations course.

In this project I will build a basic recipe website using HTML. 
The website will contain a main index page with links to several recipes.

Skills demonstrated in this project include:
- Creating HTML boilerplate
- Working with headings, paragraphs, and lists
- Creating links between pages
- Organizing files and directories
- Using Git and GitHub for version control
